## Free GitHub Pages deployment
1. Create a GitHub account.
2. Create a new public repository, e.g. `vatvriksha-tours`.
3. Upload ALL files and folders from this project.
4. Open Settings → Pages.
5. Choose Deploy from branch → main → /root → Save.
6. GitHub will provide a public URL.
7. Share that URL on WhatsApp/Instagram.

## Editing packages
Edit `js/packages.js`. Each package is one object. You can change price, duration, places, itinerary, inclusions and exclusions.

## Adding photos
Put photos in `assets/images/` and update the `image` field in `js/packages.js`.

## Adding videos
Put videos in `assets/videos/` and add a video section later; keep large videos compressed for faster loading.
